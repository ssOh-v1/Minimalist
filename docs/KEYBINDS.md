# ⌨️ Бинды Minimalist-for-arch

`SUPER` — основная модификатор-клавиша (клавиша Windows).

---

## 🚀 Основные

| Комбинация | Действие |
|---|---|
| `SUPER + Return` | Открыть терминал (Kitty) |
| `SUPER + E` | Открыть файловый менеджер (Thunar) |
| `SUPER + R` | Открыть лаунчер (Fuzzel) |
| `SUPER + B` | Открыть Firefox |
| `SUPER + S` | Открыть Steam |
| `SUPER + D` | Открыть Discord |
| `SUPER + P` | Открыть Spotify |

---

## 🪟 Управление окнами

| Комбинация | Действие |
|---|---|
| `SUPER + Q` | Закрыть активное окно |
| `SUPER + F` | Полноэкранный режим |
| `SUPER + Space` | Сделать окно плавающим |
| `SUPER + SHIFT + Space` | Закрепить окно поверх других (pin) |
| `SUPER + M` | Выйти из Hyprland |
| `SUPER + N` | Перезапустить Waybar |
| `SUPER + Tab` | Переключиться на следующий рабочий стол |
| `ALT + Tab` | Переключение между окнами |

---

## 🖱️ Мышь

| Комбинация | Действие |
|---|---|
| `SUPER + ЛКМ` | Переместить окно |
| `SUPER + ПКМ` | Изменить размер окна |

---

## ⌨️ Перемещение и ресайз

| Комбинация | Действие |
|---|---|
| `SUPER + ←/→/↑/↓` | Переместить фокус |
| `SUPER + H/J/K/L` | Переместить фокус (Vim-стиль) |
| `CTRL + ALT + ←/→/↑/↓` | Переместить окно |
| `SUPER + ALT + ←/→/↑/↓` | Изменить размер окна |

---

## 🗂️ Рабочие столы

| Комбинация | Действие |
|---|---|
| `SUPER + 1..9` | Переключиться на рабочий стол |
| `SUPER + SHIFT + 1..9` | Переместить окно на рабочий стол |

---

## 🔊 Мультимедиа

| Комбинация | Действие |
|---|---|
| `XF86AudioRaiseVolume` | Увеличить громкость |
| `XF86AudioLowerVolume` | Уменьшить громкость |
| `XF86AudioMute` | Выключить/включить звук |
| `XF86MonBrightnessUp` | Увеличить яркость |
| `XF86MonBrightnessDown` | Уменьшить яркость |
| `SUPER + W` | Сменить обои |

---

## 🛠️ Утилиты

| Комбинация | Действие |
|---|---|
| `SUPER + V` | История буфера обмена (cliphist) |
| `SUPER + SHIFT + C` | Выбрать цвет (hyprpicker) |
| `SUPER + L` | Заблокировать экран (hyprlock) |
| `Print` | Скриншот всего экрана |
| `SUPER + SHIFT + S` | Скриншот (кастомный скрипт) |
| `ALT + SHIFT + L` | Переключить раскладку клавиатуры |
| `SUPER + T` | Меню тем |
| `SUPER + ALT + V` | Меню буфера обмена |
| `ALT + D` | Очистить буфер обмена |
| `SUPER + CTRL + D` | Удалить из буфера обмена |
| `SUPER + ALT + B` | Выбор темы Waybar |

# Горячие клавиши Minimalist

Открыть эту подсказку в любой момент: **SUPER + /**

## Приложения
| Клавиши | Действие |
|---|---|
| SUPER + Enter | Терминал (kitty) |
| SUPER + E | Файловый менеджер (nemo) |
| SUPER + R | Запуск приложений (fuzzel) |
| SUPER + B | Firefox |
| SUPER + S | Steam |
| SUPER + D | Discord |
| SUPER + P | Spotify |
| SUPER + T | Telegram |
| CTRL + S | Показать/скрыть панель Spotify |

## Окна
| Клавиши | Действие |
|---|---|
| SUPER + Q | Закрыть окно |
| SUPER + F | Полноэкранный режим |
| SUPER + N | Перезапустить waybar |
| SUPER + M | Выйти из Hyprland |
| SUPER + Space | Сделать окно плавающим |
| SUPER + SHIFT + Space | Закрепить окно поверх (pin) |
| CTRL + ALT + ← ↑ → ↓ | Переместить окно |
| SUPER + ALT + ← ↑ → ↓ | Изменить размер окна |
| SUPER + ЛКМ (перетаскивание) | Переместить окно мышью |
| SUPER + ПКМ (перетаскивание) | Изменить размер мышью |

## Рабочие столы и фокус
| Клавиши | Действие |
|---|---|
| SUPER + Tab | Переключить рабочий стол |
| ALT + Tab | Переключить окно (fuzzel-свитчер) |
| SUPER + 1…9 | Перейти на рабочий стол 1–9 |
| SUPER + SHIFT + 1…9 | Перенести окно на рабочий стол 1–9 |
| SUPER + ← ↑ → ↓ | Переключить фокус |
| SUPER + H/J/K/L | Переключить фокус (vim-стиль) |

## Обои и тема
| Клавиши | Действие |
|---|---|
| SUPER + W | Сменить обои |
| SUPER + X | Меню темы |
| SUPER + ALT + B | Выбор темы waybar |

## Буфер обмена и утилиты
| Клавиши | Действие |
|---|---|
| SUPER + V | История буфера обмена |
| CTRL + Delete | Удалить один элемент из буфера |
| ALT + Delete | Очистить буфер обмена полностью |
| SUPER + SHIFT + C | Пипетка цвета (hyprpicker) |
| Print | Скриншот |
| SUPER + SHIFT + S | Скриншот (альтернативный бинд) |
| SUPER + L | Заблокировать экран |
| ALT + правый Shift | Переключить раскладку клавиатуры |

## Мультимедиа (без модификатора)
| Клавиши | Действие |
|---|---|
| Volume Up / Down | Громкость +/- |
| Mute | Отключить звук |
| Brightness Up / Down | Яркость +/- |

## Справка
| Клавиши | Действие |
|---|---|
| SUPER + / | Открыть эту подсказку |
